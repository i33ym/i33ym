Multiply inputs by weights, sum them up, decide.

The Math

Don't worry, it's just arithmetic

Step 1: Weighted Sum

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Or in vector form: z = w · x + b

Step 2: Decision

ŷ = 1 if z ≥ 0, else 0

That's it. That's the whole forward pass.

💡 Intuition

The dot product w · x measures how "similar" the input is to the weight vector.

High similarity → positive → class 1

Low similarity → negative → class 0

The Geometry

What is the perceptron actually doing?

Finding a Line

In 2D: the perceptron finds a line that separates two classes

In 3D: a plane

In nD: a hyperplane

The Decision Boundary

w · x + b = 0

Points on one side → class 0

Points on the other side → class 1

💡 Intuition

Weights control the orientation of the line

Bias controls the position (shifts it up/down)

The Learning Algorithm

How does it find the right weights?

The Update Rule

w = w + η(y - ŷ)x

η (eta) = learning rate

In Plain English

1
Pick a training example
2
Make a prediction
3
If wrong: nudge weights toward correct answer
4
If correct: do nothing
5
Repeat until no errors (or max iterations)

Why Does This Work?

Predicted 0, actual 1 → y - ŷ = +1

Weights move toward the input

Predicted 1, actual 0 → y - ŷ = -1

Weights move away from the input

The Code

~40 lines of Python

The Perceptron Class

import numpy as np

class Perceptron:
    def __init__(self, eta=0.01, max_iters=50):
        self.eta = eta
        self.max_iters = max_iters
    
    def fit(self, X, y):
        self.weights_ = np.random.normal(0, 0.01, X.shape[1])
        self.bias_ = 0.0
        self.errors_ = []
        
        for epoch in range(self.max_iters):
            errors = 0
            for xi, target in zip(X, y):
                prediction = self.predict(xi)
                delta = self.eta * (target - prediction)
                self.weights_ += delta * xi
                self.bias_ += delta
                errors += int(delta != 0)
            
            self.errors_.append(errors)
            if errors == 0:
                break
        
        return self

Prediction Methods

def net_input(self, X):
    return np.dot(X, self.weights_) + self.bias_

def predict(self, X):
    return np.where(self.net_input(X) >= 0.0, 1, 0)

Using It

X = ...  # features: sepal length, petal length
y = ...  # labels: 0 or 1

ppn = Perceptron(eta=0.1, max_iters=10)
ppn.fit(X, y)

accuracy = np.mean(ppn.predict(X) == y)
print(f"Accuracy: {accuracy * 100:.1f}%")  # 100%!

Linear Separability

The perceptron only works when data is linearly separable

This was the critique that killed AI for a decade.
